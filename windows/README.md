# TabCtrl Native Bridge — Windows

Self-contained install bundle. Use this folder if you're on Windows.

## One-click install

Double-click **`install.bat`**. It runs `install.ps1` with `-ExecutionPolicy
Bypass` for you, registers the host with Chrome, and pauses on completion.

By default it registers for **Google Chrome** with the Chrome Web Store
extension id (`bniefocpdldneagigjlhbllgdjohmeie`).

## Advanced install

Run `install.ps1` directly from a PowerShell prompt for non-default setups:

```powershell
# Edge instead of Chrome:
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Chrome Edge

# Development build with a load-unpacked extension id:
powershell -ExecutionPolicy Bypass -File .\install.ps1 -ExtensionId <id>

# Derive the dev extension id from the local manifest.json key:
powershell -ExecutionPolicy Bypass -File .\install.ps1 -UseManifestKey
```

## Uninstall

Double-click **`uninstall.bat`** — removes the Chrome registry key and the
local `com.tabctrl.bridge.installed.json`. Pass `-Chrome Edge` (or `-Chrome All`)
to widen the scope.

## What's in this folder

| File | Purpose |
|---|---|
| `install.bat` | One-click installer (zero-arg, Chrome) |
| `install.ps1` | Parameterized installer (advanced) |
| `uninstall.bat` / `uninstall.ps1` | Removes registry and local manifest |
| `tabctrl-bridge.cmd` | Host launcher invoked by Chrome |
| `host.cjs` | Native messaging host (sync'd copy of `../common/host.cjs`) |
| `generate-manifest.cjs` | Manifest generator (sync'd copy) |
| `bridge.config.json` | Allowlist of CLIs this host may run |
| `bridge.config.schema.json` | Editor schema for the config |
| `com.tabctrl.bridge.json` | Manifest template |
| `com.tabctrl.bridge.installed.json` | Generated by `install.ps1`, registered with Chrome |

## Requirements

- Windows 10 / 11
- Node.js installed and reachable on `PATH` (run `node --version` to verify)
- Google Chrome or Microsoft Edge with the TabCtrl extension loaded

## Verify the install

In TabCtrl: enable **Settings → Lab**, then run **Check bridge**. You should
see `bridge: tabctrl-native` and your platform reported.

If `ping` fails, confirm `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.tabctrl.bridge`
in the registry points at the `com.tabctrl.bridge.installed.json` inside this
folder.
